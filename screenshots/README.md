# Screenshots

Drop the demo images here so they render in the main [`README.md`](../README.md) and
[`SUBMISSION.md`](../SUBMISSION.md). Use these exact filenames so the existing image links work:

| Filename | What it should show |
|---|---|
| `home.png` | The app home screen — title, the 5 task tabs, the input box. |
| `run-comparison.png` | A completed run: **Original output** and **Improved output** panels side by side (e.g. the Summarization or Extraction sample). |
| `prompts-expanded.png` | The "Original prompt" / "Improved prompt" cards expanded via *Show prompt*, so the grader can see both prompts. |

Tip: PNG, roughly 1200–1600px wide, captured in a maximized browser window for a clean look.
You already have several of these from testing — just save them here with the names above.
